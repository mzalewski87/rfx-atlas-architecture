# Viewer source

Zero-dependency static app; open `index.html` directly. The layout, components, flows, scenarios
and slides are data in `js/data.js`; the engine files are generic and rarely change. See the
repository README for how to keep the data in step with the RFx Atlas architecture.

`css/styles.css` is shared with the viewer of an earlier project by the same author; RFx Atlas
additions (zones, link types, scenario states) are in `css/rfx.css`.
